# Persistty 首版需求与验收

## 目标与用户价值

在已有Debian开发机上提供仅通过WireGuard使用的持久网页终端与轻量文件工具。AI、后端和前端开发任务长期运行，换设备或重新打开浏览器可继续操作，不建设完整IDE。

本任务交付调研与规划，状态仍为planning。本文为需求澄清后的最终审查稿，不代表已批准实施；没有运行task.py start或实现产品。

## 范围内需求

### P01 设备、界面与资产

桌面用统一编辑器入口下的Monaco，手机用基础文本编辑器，不使用移动Monaco，不提供Git/草稿diff。手机终端快捷栏覆盖方向、Ctrl、Alt、Esc、Tab、Ctrl+C/L/S/Z及`/`，发真实按键而非可见`^C`文本。手机文件上传/下载、目录ZIP下载，不做目录上传；桌面文件/目录上传和完整文件操作。手机文件操作采用可用菜单，不要求复刻桌面拖拽。

首版验收电脑Chrome/Edge、Android Chrome/iOS Safari的实现时维护版本；其他浏览器不拦截但不保证完整兼容。深色/浅色主题；内置JetBrains Mono Nerd Font NL和等宽兜底；Material图标按文件名/复合后缀映射并回退未知类型。分发前验证实际字体/图标许可。

来源：U04..U05、U08..U09、U13..U15、U27、U50、U57。

### P02 持久终端与恢复

AI、后端、npm run dev为独立长期终端。页面关闭、视图卸载、断网、登出、认证过期、Web/Nginx重启不终止任务。重连恢复仍存活原会话的可操作当前画面/近期历史；保留行数可配置，超限淘汰最旧内容，按需渲染默认开启，不是无限历史。

普通scrollback与全屏TUI分别恢复，不把capture-pane文本当完整原始输出重放。整机重启/断电后旧会话显示已结束、保留记录，不重跑命令/复活原身份。依赖故障、状态未知显示不可用，不直接判已结束。

显式终止采用日常终端范围，不追踪清理故意nohup/disown/daemon、独立服务或远端任务。来源：U01..U03、U18..U20、U61。

### P03 多端控制与终止倒计时

多电脑/手机同时查看同一终端，仅一个控制端；新观察端不抢占。显式接管后旧端只读；后端校验键盘/粘贴/快捷键/resize，PTY尺寸仅由控制端决定。重连不夺回已转移权限，不重放输入。

仅当前控制端发起终止，接管后有权发起。所有查看端显示服务端统一截止时间的弹窗，时长可配置；截止前任一已鉴权查看端可取消。期间任务继续，取消/执行串行裁决，新连接获得当前状态；取消成功不能再终止。关闭视图不触发计时，离线端不保证收到通知，不拦截shell内exit/kill、管理员操作或系统故障。来源：U17、U51..U52。

### P04 工作根与共享资源

底部状态栏选择当前用户可访问的任意普通目录，不限固定项目根。切根时列明新范围外的已打开文件并确认；是则关闭这些文件，否保持原根/标签；仍在新范围内的文件不全部关闭。未成功保存内容保留草稿，不强制写回或丢弃。

新终端只用当前浏览器状态栏根，不继承已有shell的cwd；切根不向已有终端注入cd、不结束任务。初次默认根为设计建议，同浏览器恢复记住的有效根。

真实工作区/终端/名称共享，各浏览器独立记忆根选择、标签/选中项、布局/主题。普通文件API仍限定明确选定根内的安全相对路径/目标身份，不变为任意绝对路径副作用接口。shell保留实际UID权限，不宣传沙箱。来源：U37、U53..U56。

### P05 完整基础文件管理

新建文件/目录、重命名、复制、剪切/粘贴、移动及树内拖拽；树内服务器文件操作不同于本机拖入上传。冲突显式处理，不默认覆盖，失败/部分完成准确呈现。拒绝目录移入自身/子目录；移动/重命名更新编辑器路径，旧路径不被自动保存重建。

删除列明文件/目录并确认，绑定确认时的目标身份/版本，执行前复验；检测到同路径目标替换或变化时拒绝旧确认并要求重新确认。永久删除、无回收站；取消零删除。已打开文件删除后不可用，待保存输入不丢。目录变化/部分删除准确报告，不承诺整树原子回滚或非协作修改下绝对CAS。普通文件操作不复用单文件提权授权执行批量动作。

监听外部文件/目录创建、重命名、移动、删除与内容变化，刷新当前文件树及相关已打开文件状态；不得因刷新清空待保存输入。重连、监听丢失/溢出后重新列举并复验，不能仅依赖未丢失的增量事件。来源：U06、U47..U48。

### P06 内容识别与轻量编辑

内容校验文本/二进制，后缀仅辅助语言推断；无后缀/特殊后缀文本可编辑，伪装代码后缀二进制不误解码保存。首版仅有效UTF-8，含BOM，保留换行/无末尾换行；其他编码不自动转换写回但可下载。

桌面可切换语言模式，不改名/编码、不绕过二进制判定。Monaco内置高亮及官网默认示例范围的有限提示，不加项目级提示/LSP/语法语义检查或问题列表；各语言提示能力不同。来源：U32..U34；[示例](https://microsoft.github.io/monaco-editor/)、[独立诊断配置](https://microsoft.github.io/monaco-editor/typedoc/interfaces/languages_features_typescript_register.DiagnosticsOptions.html)。

### P07 自动保存与并发保护

桌面/手机默认自动保存，准确区分待保存/保存中/已保存/冲突/失败。保存前和发布前复验版本，检测外部修改拒绝写入、保留磁盘新内容和本地输入，不自动合并/强制重试。保存期间输入不被旧响应标为已保存。

无待保存输入时外部修改自动刷新，有输入则保留并提示冲突。由人拆分任务避免同文件竞争；接受非协作writer在检查与发布间的极短窗口，不承诺绝对CAS。完整内容原子发布不等于消除窗口。来源：U06、U21..U22。

### P08 本地草稿

同浏览器/同站点保留未成功保存内容，不跨设备同步。桌面恢复前diff草稿与最新服务器内容，检查版本，区分Git diff。恢复到待处理缓冲区不立即自动写回；明确确认后保存仍复验，外部再改再冲突。

手机无diff：服务器未变可确认恢复，已变则保留/导出，电脑需人工取得导出内容。配额/隐私模式/站点清理限制可见，不保证所有崩溃前输入。成功清理只针对已落盘草稿版本，不删除后续新输入。来源：U49..U50。

### P09 图片与二进制

图片/SVG内容识别与受限预览，其余二进制类型/大小/下载入口，不做PDF/Office阅读或hex。二进制原字节传输，不进入文本搜索/编辑。SVG禁脚本/外部资源及宿主页访问，不插入宿主DOM；大小、像素/解码资源有界。来源：U07、U30..U31；[安全证据](research/browser-transfer-assets.md)。

### P10 只读Git

变更列表、提交历史、提交详情diff、相对HEAD的行级色条；色条包含尚未保存输入，保存不清除未提交标记，HEAD变化刷新基线。提交详情与指定父提交比较；根提交/merge/无HEAD明确状态，不虚构对象。

当前工作区与所选本地tag/分支只读比较，不切分支、不任意两引用比较，不提供暂存/提交/拉取/推送/合并按钮，不自动获取缺失对象。终端Git操作后刷新，磁盘、缓冲区和基线明确区分。限制CLI辅助程序/隐式写入/根外读取，不能只凭命令名声明只读。来源：U07、U23..U26；[语义证据](research/files-search-git.md)。

### P11 搜索替换

普通文本、大小写、全词、单行正则与捕获组，不跨行；仅可编辑UTF-8。遵守.gitignore，默认排除node_modules等依赖及.git元数据，include不能意外重新纳入。先预览确认、逐文件复验版本，冲突/失败准确反馈，不假装成功项自动回滚；搜索/预览/应用引擎语义及快照一致。来源：U11、U35。

### P12 传输与普通ZIP

日常代码项目规模，单文件/批次/暂存容量可配置。桌面文件/目录上传，手机文件上传；页面存活且源可读时断网/Web重启可续传，服务器状态持久化。关页/刷新后重新上传，不跨设备续传。

同路径同名实际内容相同跳过，不同则询问替换；拒绝保留，确认后目标又变则再次冲突。逐文件结果准确，不默认自动改名保留两份。完整校验后发布，取消/过期清理有界暂存。

文件原样下载，目录普通ZIP，不是同一时点快照/备份。检测读取失败/变化提示，不把HTTP 200当ZIP完成。路径/特殊文件/symlink/空目录及超限准确报告，不静默漏项却宣称全部成功。来源：U10、U27..U30、U62。

### P13 登录、部署与单文件提权

后端单密码鉴权覆盖全部HTTP/WS资源；记住登录、有效期可配置、主动退出，到期/撤销断控制不杀任务，多设备登录不互踢。现有非root开发用户运行，终端正常sudo。

首版VPN内HTTP密码弹窗提权，仅配置允许目标、单文件一次内容保存。应用登录不等于sudo授权，密码不缓存供后续自动保存，不扩展目录/其他文件/上传/批量替换/任意命令权限；目标或内容版本变化不能沿用旧授权。取消/失败/过期不写入、不丢输入。

密码不持久化、不记日志/追踪/错误响应，不放URL/命令参数/终端回显；短时验证后清理字段/引用，不承诺托管运行时所有副本绝对擦除。独立高权限边界复验允许目标、身份、内容版本，Web不整体root运行。

验证VPN直达与无公网应用入口/隧道外网络转发；HTTP/ws不声称自带加密，不自制加密冒充HTTPS。保留会话、Origin/CSRF/CSP、预览隔离，明确HTTP无Secure Cookie/HTTPS安全上下文。原始终端输入不记日志、不广播观察端，可信浏览器/页面/后端/主机仍是信任边界。前提不满足拒绝启用，不降级为任意root写入。

来源：U05、U16、U36、U38..U46；[WireGuard](https://www.wireguard.com/)、[TLS](https://cheatsheetseries.owasp.org/cheatsheets/Transport_Layer_Security_Cheat_Sheet.html)、[WebSocket](https://cheatsheetseries.owasp.org/cheatsheets/WebSocket_Security_Cheat_Sheet.html)、[VS Code参考](https://github.com/microsoft/vscode/blob/main/src/vs/workbench/services/workingCopy/common/storedFileWorkingCopy.ts)。

### P14 终端网页链接

HTTP/HTTPS链接Ctrl点击原样新tab打开；观察端可打开，不向PTY注入字符。手机提供明确打开动作而非误触选中/滚动。scheme白名单、opener隔离，端口/参数/折行/标点正确识别。不映射localhost/0.0.0.0，不提供代理/预览入口，监听/可达性由用户处理。来源：U58..U60；[xterm web-links](https://github.com/xtermjs/xterm.js/tree/master/addons/addon-web-links)。

## 风险与实施前提

1. tmux独立cgroup/固定socket/隐式启动竞态、真实TUI恢复须目标Debian实验；未验证不宣称持久功能完成。
2. 任意工作根不取消所选根安全I/O；CLI读取、symlink/hardlink与Git副作用按研究控制。
3. 非协作writer竞争窗口已接受，hash/rename非绝对CAS；目录/批次可能部分成功，非全批事务。
4. HTTP为明确VPN特例，sudo/helper与root-owned策略、授权/凭证/版本复验独立安全验证。失败不得悄悄删功能或扩大权限，应暂停该交付重新评审。
5. 默认参数/工程取舍在设计中明确列为审查建议，不是已测试保证；实质变化须重新审查。
