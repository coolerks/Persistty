# W01 执行

## 顺序与所有权
1. 主会话记录父批准、对齐冲突规范、激活本任务。
2. 后端implement负责go.mod/go.sum、cmd/**、internal/**、tests/contracts/**：配置/密码/认证/DB/真实读接口与测试，明确共享fixture；不改web/deploy/规范。
3. 前端implement负责web/**：官方组件查询/引入、真实客户端/严格decoder、登录/项目路由/列表/主题/布局类型及测试；不改Go/fixture/deploy/规范。直接依赖步骤2共享契约，网络测试等待后端可运行；可并行构建静态类型与UI。
4. 主会话负责deploy/**、README/构建说明、规范和任务记录；部署配置不得启停tmux或安装root helper。check代理在实现结束后复核和修复，不能与实现代理同时改相同文件。
5. 运行go test ./...、go test -race ./...、go vet ./...；npm --prefix web run lint/typecheck/test/build。运行真实本地HTTP和浏览器截图/桌面手机路由认证检查；启动可试用开发服务器。
