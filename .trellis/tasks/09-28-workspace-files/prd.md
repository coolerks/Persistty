# W04 多文件夹项目与文件管理

## 目标与依据

让用户从真实项目面板建立、维护和打开由多个 Debian 普通目录组成的项目，在浏览器中安全地浏览和管理文件，并完成可恢复上传、文件下载和目录 ZIP。此包以已提交并归档的 W01 基础服务与 W02 Debian 实验为依赖；父任务 [PRD](../09-26-requirements-research/prd.md) P04/P05/P12、[设计](../09-26-requirements-research/design.md) 与 [实施计划](../09-26-requirements-research/implement.md) 是批准来源。W02 的 Landlock 临时树实验不算 W04 正式文件 API 沙箱。

## 范围内需求

### 项目与身份

- 项目可创建、列出、打开、改名、修改关联文件夹与主文件夹、移除配置；每个项目至少一个文件夹且恰有一个主文件夹。用户可选择当前服务用户可访问的任意普通目录，不限预设白名单；路径须在服务器验证真实身份。稳定 ID/书签不随项目名称变化。
- 新建/修改项目使用同一个 Debian 服务器目录选择器：路径输入框可直接输入绝对路径，也能通过目录列表逐层选择、返回上级并确认；只列目录、不把浏览器设备的本地文件路径当服务器路径。输入路径和列表选择走同一后端身份/权限校验，非法或不可访问时留在弹窗并提示。
- 每个文件 API 使用 `project_id + folder_id + relative_path + project_version` 明确定位；同名相对路径不混淆，重叠根允许但真实文件操作不得重复。关联删除或根身份失效后旧请求不能继续读取/写入；项目删除只清元数据，不删真实文件、不杀终端。
- 项目配置变更使用预期版本，竞争返回 conflict。移除主文件夹时必须同时选择剩余主文件夹；最后一个文件夹不能用配置更新移除。项目移除后书签页明确失效，提供项目面板及统一终端入口；本浏览器未保存草稿的保留/导出属于 W05 交互，W04 不得清除其存储。

### 文件树与文件操作

- 文件资源管理器分别显示项目关联文件夹及其树，支持外部创建/修改/移动/删除后的更新。目录列表无静默截断；大目录分页或有界错误。断线、事件丢失/溢出后重新列举，不把事件当事实；刷新不得清空待编辑输入。
- 文件与目录新建、重命名、复制、移动/剪切粘贴、树内桌面拖拽及永久删除均支持；手机使用菜单，不要求拖拽。源/目标分别带 folder 身份，不接受任意客户端绝对目标。目标已存在默认拒绝，不隐式覆盖或改名；目录不能移入自身/子孙。跨文件系统移动逐项报告，不能伪装为原子操作。
- 删除列明目标并确认；取消不发删除请求。确认绑定文件身份与强版本，执行前目标改变则拒绝旧确认。目录批量操作发生失败准确报告已成功/失败部分，不宣称整批回滚。移除关联与删除真实文件必须是不同操作。
- 文件内容读取区分有效 UTF-8/BOM 与二进制，按原字节形成 hash/版本。普通文本保存以 expected version 保护，冲突零写入，同目录临时文件完整写入、同步后原子发布；保留普通权限位，不能继承 setuid/setgid。外部 writer 在最终复验和 rename 间的窗口按父需求明确标示，不承诺绝对 CAS。W05 才实现 Monaco/手机编辑器、自动保存与草稿 UI；W04 提供其安全后端契约和基本内容入口。

### 传输

- 桌面支持文件和目录上传（含可表示的空目录），手机支持文件上传；服务器验证路径、块 hash、完整 hash、配额和项目关联，在 Web 重启后可恢复页面仍持有源文件的上传，关页/刷新不保证续传。目标同名同路径且内容相同跳过；不同内容须明确确认替换且发布前复验。只提供 skip/replace，不自动 `keep_both`。
- 文件原字节下载；目录构建普通 ZIP 后再提供下载，保留空目录，拒绝越界链接/特殊文件并准确报告失败。ZIP 非一致时点快照，不能把生成中错误伪装成已完成的 HTTP 200。上传/ZIP 的取消、过期与暂存容量有界，只清理本应用自身资源。

## 验收标准

- A01 创建多根项目、指定唯一主文件夹，改名/增删关联/换主文件夹与配置竞争符合约束；直接书签、刷新与项目面板打开保持稳定 ID；移除项目不删磁盘、不触碰已有终端元数据/进程。
- A02 无权/失效目录、同名与重叠根、目录移出原树时，旧 project/folder/version 请求不能越界或错误改绑；有效覆盖复验后才可换 folder 身份。
- A03 多根文件树对空目录、分页、Unicode、前导短横线、特殊文件给出准确状态；外部变更及断线/溢出经重新列举收敛，不清除未保存输入。
- A04 文件/目录 CRUD、同根/跨根复制移动、目标冲突、移动进自身、删除确认后替换、部分失败均有真实磁盘集成验证；取消删除零副作用。
- A05 UTF-8/BOM/混合换行/无末尾换行与二进制判定、原字节 hash、同 mtime/size 内容变化冲突、原子保存/故障注入与权限位保留通过；旧关联保存拒绝。
- A06 上传文件/目录、空目录、重复块、错误 hash、断线及 Web 重启续传、容量/TTL、同内容跳过、不同内容确认和确认后变化冲突均可验证；手机只提供文件上传入口。
- A07 文件下载原字节一致；目录 ZIP 可真实解压核对结构、空目录和字节；读中变化/特殊文件/越界链接/配额失败不会报告完成。
- A08 Go test/race/vet、前端 lint/typecheck/test/build、共享 API fixture、真实 HTTP/SQLite/filesystem 集成和桌面/手机浏览器关键流程通过；缺依赖/未执行逐项标注，不将 W05/W03/W07 验收混入 W04。

## 范围外

终端生命周期/控制与运行时 UI（W03），Monaco/移动编辑器、自动保存/草稿 diff 与完整布局（W05），搜索替换/只读 Git（W06），单文件 sudo 提权（W07），正式 Debian 部署与多设备全矩阵（W08）。W04 不开放任意命令、任意绝对路径文件 API、Git 写操作或回收站。
