# W05/W06 真实手机操作清单

状态：待设备/系统/浏览器信息及可访问隔离地址。只有实际在物理手机执行并记录结果才可勾选；桌面viewport/hasTouch/WebKit引擎不替代。

## 前置条件

使用独立测试项目、虚构密码和合成文件，服务器端为本轮隔离实例；确认手机连接方式与可访问Origin后提供实际地址。现有Debianbrowser harness仅loopback与15分钟期限，不为手机访问改变正式服务、关闭鉴权或延长该期限。结果只记录设备类型/系统浏览器版本、操作及结果，不记录私有地址/密码或用户文件正文。

## 操作与判定

- [ ] 打开普通测试文本，调出软键盘后当前行、文件动作及导航可访问，页面不出现横向溢出或遮挡导致无法完成操作。
- [ ] 中文输入法连续输入、候选选择、删除重输、emoji及换行；完成后正文与服务器一致，没有候选被错误清空或重复输入。
- [ ] 自动保存等待期间继续输入，再按显式保存；旧响应不丢新输入，无冲突时最终落盘一致。
- [ ] 尚未保存时旋转横屏/竖屏，仍为基础文本编辑和单内容导航，输入与光标操作保留，保存继续完成。
- [ ] 前台输入后切到其他app再返回，断网/恢复连接；脏内容及草稿保留，冲突可见，不自动覆盖。
- [ ] 刷新有草稿页面，服务器先复验，恢复不隐式PUT；基线变化只保留/导出，不提供手机强写。
- [ ] 在Search输入中文/emoji，改范围、点击结果定位、选择匹配/文件、查看原/新文本；取消不写文件，明确应用后逐文件状态准确。
- [ ] 打开只读Git状态/历史/比较，在触控滚动和返回编辑器间切换；比较窗口不写文件，当前输入保持。
- [ ] PNG/JPEG/GIF/WebP/AVIF/SVG查看、浅色/深色/跟随系统，确认实际解码和缩放；不支持格式准确提示，不能记为已支持。
- [ ] 终端软键盘/快捷键区域与中英文/Nerdglyph显示、历史返回实时，进入/离开面板不创建或终止真实会话；资源由专属隔离harness清理。

## 记录模板

设备/系统/浏览器：待填。隔离项目标识：待填。执行时间：待填。每项记录通过/失败/未执行与可复现步骤；失败保留输入后报告，不继续盲目重复写入。所有项目均未勾选通过。
