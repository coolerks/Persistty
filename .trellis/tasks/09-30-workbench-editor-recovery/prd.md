## 需求与验收

| ID | 需求 | 可观察验收 |
| --- | --- | --- |
| E01 | 共用文件缓冲区/保存调度，重叠根和多组共享真实文件 | 实际落盘；UTF-8/BOM/混合换行/无末尾换行保留，model/undo 不因移动丢失 |
| E02 | 默认 1 秒 autosave，Ctrl/Cmd+S 同入口，真实保存状态 | 保存中输入不被旧响应清理；409/权限/目标消失暂停，双方输入保留，比较后明确处理仍复验 |
| E03 | IndexedDB 按项目/真实文件/视图修订隔离，恢复先读服务器 | 刷新无隐式 PUT，桌面只读 diff，恢复后先暂停再明确保存；手机基线变化仅导出，多视图互不删除 |
| E04 | 存储失败可见、关闭/配置/文件操作保护 | 配额失败保留内存，最后视图关闭前保护；rename/move 更新路径草稿，删除不复活；重叠覆盖复验重绑，失效项目鉴权后可导出 |
| E05 | 外部事件/重连失效复验 | 干净自动刷新，脏缓冲区冲突；旧配置请求停止，无重试绕过版本 |
| P01 | 内容识别图片/SVG/二进制，有界预览 | 字节/像素限制、SVG 脚本/外链隔离、匿名拒绝、资源释放、超限/二进制只下载 |
| L01 | 上下区域仅左右组，宽屏至少三组，标签排序/移动 | 下方拒绝文件，终端同 ID/runtime/控制权，零隐式 create/terminate/input |
| L02 | 本浏览器按项目/schema/设备恢复视图 | 标签/激活/组/终端位置/顺序/Explorer 展开/尺寸/折叠恢复，手机单内容不覆盖桌面，恢复复验真实资源 |
| L03 | 收起边缘拖出，有按钮/键盘替代，窄屏保留组 | 小窗口无 document 溢出，不丢输入/终端；设备变化不销毁记录 |
| A01 | 实际 JetBrains Mono Nerd Font Mono NL 与许可 | 自托管 family/glyph/加载后重新测量，三主题不重建 model/runtime，许可随构建 |

## 范围与限制

W06 搜索/Git、W07 提权、W08 正式部署、LSP/诊断、手机 diff/多列、PDF/Office/hex、跨设备草稿不在本包。已接受非协作 writer 的最终校验/rename 短窗口，不承诺绝对 CAS。真实手机软键盘与实机矩阵未执行时不得记通过。测试仅使用自有隔离资源，不改用户现有服务/文件/终端。不自动提交、推送或归档。
