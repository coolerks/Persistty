# W06 多根搜索替换与只读 Git

## 关键边界

- 采用安全句柄生成私有文件/仓库快照，CLI 读取快照，不能通过 cwd 校验或事后过滤替代读取边界。策略详见 design.md；安全或 CLI 对照门禁失败时不得开放相应 API。
- Git 默认展示 HEAD 到磁盘的总变化，暂存/未暂存分开；编辑器标记基于 HEAD 到 buffer。仅当前内容与单个本地引用比较，不增加任意两引用比较。
- 根外 worktree 元数据、对象 alternates、未知 repository 扩展及必须依赖外部内容过滤器的仓库先报告不可用；不默默读取、联网或生成错误 clean 状态。
- 替换使用服务端生成的新内容；客户端不能提交任意绝对路径、偏移或 force 开关。预览短期有界保存，过期或 Web 重启要求重新搜索预览。
- 其他浏览器的未保存输入不由服务器推断；原有草稿与外部事件冲突保护继续生效。非协作 writer 的最终校验/rename 短窗口保留，不承诺绝对 CAS 或全项目原子快照。
