# W07 单文件提权编辑

## 目标与授权

使用户在普通文本保存因权限失败时，通过网页密码弹窗明确保存一个已允许的文件，同时保留输入、文件版本保护及非 root Web 服务边界。

2026-10-02 用户授权创建、规划并实施 W07，并将 W05/W06 剩余统一验收后移。用户随后明确回复“开始实施”，已批准最新总结，任务为 in_progress。单代理 inline。目标机 helper/broker 安装、sudoers/PAM/systemd 修改与真实系统口令实验需在精确产物可审查后另行授权；本轮不提交、推送、归档或应用系统配置。

## 背景与已确认事实

依据首版 [PRD](../archive/2026-09/09-26-requirements-research/prd.md) P13/PA15/PA19、[设计](../archive/2026-09/09-26-requirements-research/design.md)单文件提权执行边界及 [D10 结论](../archive/2026-09/09-27-debian-spike/helper-report.md)。U39～U42/U46 已明确权限失败后网页授权、配置限目标、单文件一次保存和 VPN 内 HTTP 特例，无需重问这些决定。

- 规划时普通 PUT 保存已有强版本和原子替换；权限失败仅返回通用 forbidden，尚无提权服务/API/UI。本轮已接入，具体结果见 [检查报告](check-report.md)。
- 编辑器保存失败暂停自动保存并留草稿；成功仅清理本次提交 generation。W07 在同一缓冲区接入，不能另建编辑器或丢失 undo。
- Web systemd 示例的 NoNewPrivileges=true 与子进程 sudo 提权冲突；独立非 root 授权 broker 调用固定 root-owned helper，保留 Web 现有边界。
- D10 仅有普通用户模拟及 sudo/PAM 入口存在性检查，未安装 helper、未验证真实系统认证和特权原子保存。证据与源码锚点见 [研究记录](research.md)。

## 范围与关键决定

保留已批准 tls 与 WireGuard 内 vpn_http；不扩大到公网 HTTP。授权 TTL 60 秒，仅一次已冻结文本保存，正文不缓存给后续自动保存。允许列表由 root-owned 策略按精确 target_id/绝对文件目标配置，不授予目录通配范围。界面复用现有 shadcn Dialog/Input/Field/Button，桌面与手机共用授权行为。

选择非 root 授权 broker 和短命 root helper，Web 保留 NoNewPrivileges。PAM 使用目标机现有 sudo 认证；本功能面向系统账户密码，不能假定 MFA/多轮交互可兼容。broker/helper 的安装与命令专用 sudoers 必须独立验收，不能在 Web 启动时隐式安装或修改系统。

## 范围外与延后

不新增提权读取、不可读文件浏览、新建/删除/重命名/上传/批量替换提权、全局/目录授权、口令缓存、root Web 服务或任意执行 API。W08 正式部署和升级总验收不在本任务。W05/W06 实机统一验收按用户要求延后，两任务继续 in_progress，已通过证据与未执行项保留。

取消在最终提交接受之前保证零发布；原子 rename 已接受后无法承诺回滚，查询实际结果。沿用非协作 writer 最终复验到 rename 的短窗口，不承诺绝对 CAS。崩溃处于 rename 与结果持久化之间可能为 indeterminate，禁止盲目重放。
