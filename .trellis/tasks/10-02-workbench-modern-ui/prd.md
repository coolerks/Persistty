# 新版 VS Code 风格 UI 调整

## 目标与授权
以用户图 1 的新版 VS Code 微圆角、细框线为视觉参考，更新图 2 对应的 Persistty 工作台。用户于 2026-10-02 明确授权「创建任务并规划，然后执行」；本轮完成规划后直接实施，单代理执行。

## 背景与已确认事实
- `web/src/app/styles.css` 当前活动栏、侧栏、编辑器、终端紧贴，以直线分割；编辑器选中标签有 2px 主题色顶线，树条目圆角为 0。
- `ProjectWorkbench.tsx` 以 react-resizable-panels 管理持久化尺寸，四组编辑器、上下终端和触屏单内容视图已有实现。
- 周边控件复用 shadcn base-nova Button/Tabs/Select/Menu，文件图标使用 Material Icon Theme，操作图标使用 lucide，字体已有自托管资源。
- 图 1 是外观参考，图中的 macOS 窗口、扩展、AI、问题/输出/调试面板不属于 Persistty 产品需求。

## 需求
- R1：桌面侧栏、每组编辑器和每组终端有 1px 细边框、8px 微圆角，区域间约 4px 间隔，活动栏和状态栏融入统一低对比背景。
- R2：编辑器标签去除主题色顶线和硬分隔，以背景层次、上方微圆角区分选中；文件树选中项左右内收并有 4px 圆角；终端标签和工具栏保持相同细节尺度。
- R3：浅色、深色、跟随系统使用语义变量；保留可辨的 hover、focus、选中、脏状态。移动与触屏横屏以更小外边距保留可用空间。
- R4：布局调整、收展、标签滚动、固定文件动作、多组、Monaco 与终端宿主身份及持久恢复仍遵守既有契约。

## 验收标准
- AC1 对照图 1 检查桌面浅色实渲染截图，三个主面板的边框、圆角、间隔和标签状态可见且一致（R1/R2）。
- AC2 深色与 system 跟随正常；390×844、844×390 触屏及桌面窄宽视口无 document 溢出，控制项可到达（R3）。
- AC3 拖动及键盘调整分隔器、侧栏/终端收展、多文件横向滚动、焦点/脏标记、拆分与合并保持正常（R4）。
- AC4 执行前端 lint/typecheck/test/build、适用 Playwright 专项、Go test/vet、diff 与 Markdown 本地链接检查，并记录未执行项。

## 范围外
不修改 API、认证、提权、文件写入、终端生命周期、依赖和布局持久化 schema；不新增 VS Code 专属入口，不重做项目/登录页，不改变现有 W05/W06/W07 验收状态。真实手机及 Debian 运行时未由视觉模拟替代。
