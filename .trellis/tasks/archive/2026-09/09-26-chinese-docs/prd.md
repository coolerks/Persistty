## 范围
- 中文化 AGENTS.md、.trellis 下 Markdown 及 .agents/skills 下全部技能与引用 Markdown；保留现有中文记录和有效内容。
- 按现有规范归属补齐 Explorer 操作、工作区界面恢复、文件预览的需求与验收；补充 README 的项目状态和持久化边界。
- 文件名和引用目标不变；命令、协议标识符、可执行例子及机器定位标记保持兼容。

- [x] 全范围审查通过并记录检查结果；保留已有未提交文件，不擅自提交、归档或启动产品任务。
