# W03 持久终端与多端控制

## 目标与依据

在 W01 的认证/路由与 W04 的项目/folder 契约之上，交付让 AI、后端和前端长任务跨关页、断网、登出及 Web 重启继续运行的网页终端。父任务 [PRD](../09-26-requirements-research/prd.md) P02/P03/P04/P14/P15 和 [实施计划](../09-26-requirements-research/implement.md) W03 是已批准的产品边界。[W02 实验](../09-27-debian-spike/summary.md) 只证明底层可行性；D08 历史/TUI 快照未过生产门禁。W04 已归档，项目配置与终端生命周期必须分离。

## 范围内需求

### 生命周期与项目

- 每个终端有稳定服务器 ID、独立 tmux session 与真实观测状态。新终端默认使用当前项目主文件夹，可选同项目其他文件夹；不继承已有 shell 实际 cwd。项目改名/换主文件夹不改旧进程 cwd；项目移除只解除关联，统一终端入口仍可查看、接管与终止。
- tmux server/pane 与 Web 服务生命周期分离。关页、视图隐藏/卸载、断网、登出、认证过期、Web/Nginx 重启不终止任务、不重跑命令。主机重启不恢复原进程；记录显示已结束，依赖故障显示不可用，不伪造 running。
- shell 内 exit/kill/sudo 与普通终端一致。应用级终止只作用于指定 session，不追踪已脱离会话的 daemon、远端任务，不误杀其他终端。

### 恢复、观察与控制

- 重连恢复仍可操作的当前画面与可配置、有界的近期普通历史；全屏 TUI 与普通 scrollback 分开验证。不能靠输入重放或盲拼 capture-pane/attach；超过留存量淘汰最旧内容。输出按需渲染，服务端队列有界。
- 多个电脑、手机、标签同时查看同一终端，仅一个明确控制端能发送键盘、粘贴、快捷键和 resize。新观察端不抢占；显式接管后旧端失权，服务端 generation 拒绝旧输入与尺寸。重连不夺回已转移控制权，也不自动重发结果不确定的命令。
- 手机快捷栏提供方向、Ctrl、Alt、Esc、Tab、Ctrl+C/L/S/Z 和 `/`，发送真实按键而非可见控制文本。终端 HTTP/HTTPS 链接桌面 Ctrl 点击/手机显式动作原样新标签打开；不改写 localhost，不提供预览代理。

### 终止与视图

- 仅控制端发起应用级终止，服务端维护每终端唯一、可配置的倒计时截止。所有在线查看端及期间新连接看到同一截止，任一鉴权查看端可在截止前取消；取消与执行串行裁决，取消成功不可再终止。发起者失效、控制转移或 Web 重启取消 pending，不把未知结果当已终止。
- 下方整面板 X 仅收起，零终止请求；下方单会话删除和上方终端标签 X 走同一终止流程。观察端需先接管，取消/失败保留入口。终端上/下移动仅改变本浏览器视图，不复制 session、不重跑命令、不改变其他端布局/控制权。W05 完成全部布局与文件编辑状态集成。

## 验收标准

- T01 三个独立会话运行计数、HTTP 和确定性 TUI；关页/断网/登出/Web 正常与强制重启后，原 pane PID/start time/cgroup 与任务输出持续，重新登录可操作；缺 tmux server 时 503，Web 不隐式启动新 server。
- T02 普通历史及 TUI 当前画面在持续输出、resize、重连和 Web 重启后可操作，无已知重复/遗漏；有界留存、UTF-8/ANSI、alternate、鼠标/粘贴/控制键测试通过。恢复机制未过门禁时不开放正式 UI，不宣称 W03 完成。
- T03 多端同时观察，仅 controller 输入/resize 有效；接管后旧 generation 帧被拒，慢端不阻塞 pane；恢复不重发输入。
- T04 全端统一倒计时与新连接可见；非 controller 不能发起，任一鉴权端可取消；竞态、Web 重启、发起端断开或转移的裁决可重复验证，只有到期且仍有效才精确终止目标。
- T05 新终端使用项目主或所选关联 folder，旧 cwd 不随配置变化；项目移除后原 PID 继续，统一入口可接管/终止；项目外 `cd` 不扩大文件 API。
- T06 面板收起、上方标签关闭、单会话删除语义准确；宿主移动保持 ID/PID/权限且不创建、重放或终止；手机快捷栏和链接行为通过。
- T07 Go test/race/vet、前端 lint/typecheck/test/build、共享 fixture、HTTP/WS 安全矩阵、真实 Debian/systemd 与桌面/手机浏览器关键路径通过；只清理自身测试资源，不把 W05/W07/W08 算入。

## 范围外

完整编辑/草稿及全部布局细节（W05）、搜索/Git（W06）、单文件提权（W07）、正式部署与真机全矩阵（W08）。不恢复主机重启前的进程内存，不承诺无界原始终端录像、清理 daemon/远端任务、网页 shell 沙箱或多端同时输入。
