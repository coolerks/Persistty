## 需求

### UI01 合并顶部栏

- 移除独立品牌顶栏，把其内容合并到现有项目标题行。
- 项目名称与编辑项目入口移至左侧，不再居中。
- 品牌/项目导航、主题切换与退出登录保持可达，不因精简布局删除功能。
- 证据：`web/src/app/App.tsx:39` 是独立顶栏，`web/src/features/workspaces/ProjectWorkbench.tsx:65` 是项目标题行；截图明确标注合并与左移。

### UI02 精简终端头部

- 移除独立“终端标题/新终端目录选择”行；保留会话标签行。
- 移除独立“工作目录/运行状态”行。
- 移除独立“连接状态/控制权/接管”行。
- 保留新建、创建目录选择、刷新、收起、上下移动、历史、连接重试、接管与显式终止的现有能力；入口见 UI05..UI10。不通过新增另一条常驻行替代被删除的行。
- 每个操作明确其 terminal ID：标签按钮/右键菜单作用于该标签目标，不能误操作另一个选中终端；批量目标需列明。不能隐式接管、隐藏失败或混淆其他终端的状态。
- 证据：`web/src/features/terminal/TerminalWorkspace.tsx:59`（标题）、`:75`（标签）、`:84`（目录状态）；`web/src/features/terminal/TerminalSession.tsx:259`（连接控制）。

### UI03 工作台整页溢出修复

- 严重性 P2：用户截图显示工作台整体可向下滚动，底部状态栏下方出现大块空白，损害固定工作台体验。
- 项目工作台的顶部合并栏与底部状态栏始终在可视区域内；只有文件树、编辑器、终端历史等内容区域内部滚动。
- 保留内容内部滚动、触控/键盘可达性和面板尺寸调整，不以全局禁用滚动或截断内容掩盖溢出。
- 测量并修复实际尺寸约束链。排查位置：`web/src/app/styles.css:76`、`:81`、`:87`、`:155`、`:170`；只读测量发现文件树越界绝对定位隐藏标签的祖先缺少定位边界，见尺寸证据。这些线索不代表已通过对照试验确定根因。

### UI04 保持资源与安全行为

- 上下移动、标签切换、折叠和工具栏变化不重建原 xterm/WS、不重跑命令、不终止 tmux。
- 下方面板 X 只收起；单终端删除和上方终端标签 X 仍走当前多端可取消倒计时，只由控制端发起。
- 文件标签关闭只关闭文件视图；登录退出不终止终端；状态/权限仍以服务端为权威。
- 保持已批准技术栈与 shadcn/ui 复用约束，不更换框架、组件系统或引入直接 Radix 实现。

### UI05 标签与三种显式接管入口

- 未取得本端控制权时，在每个标签最前面显示专用图标；已取得控制权时不显示该图标。图标有中文提示和无障碍名称，不能只靠颜色表示权限。
- 点击该图标执行对应终端的显式接管；右键菜单也提供“接管”，复用同一动作，不启动新会话。
- 未接管时尝试输入命令，弹窗询问是否接管；取消不接管，确认且服务器确认成功后允许正常输入/执行。用户已确认 Q05“不保留”：首次触发的字符、粘贴、回车或控制字节不缓存、不补发、不写入 PTY；提示期间不累积输入。接管成功后焦点回终端，由用户重新输入。
- 标签末尾的 X 在鼠标悬停或键盘聚焦时出现，含义为终止该终端而非仅移除视图；点击进入既有倒计时流程。触屏替代入口见 UI09。
- 单终端确认/倒计时对话框均显示目标终端名称，修复当前对话框仅泛称“此终端”的问题；取消/失败不移除终端。
- 证据：当前 stdin 在 `web/src/features/terminal/TerminalSession.tsx:78`、`:132` 被关闭/按角色更新；输入事件在 `:117`；单个倒计时对话框在 `:285`；服务器仍复验 controller/generation。

### UI06 标签末尾新建与目录菜单

- 会话标签末尾放一个 +，不另占标题行。
- 项目仅有一个关联目录时，点击 + 直接在该目录新建终端。
- 项目有多个关联目录时，点击 + 显示 dropdown，选择目录后创建终端。菜单符合新增原型，目录选择复用服务器 folder ID/项目版本，不从显示名称推断真实路径。
- 沿用新终端使用项目关联目录、不继承旧 shell 实际 cwd 的既有需求，不把新建变成对旧进程执行 cd。

### UI07 自动命名与重命名

- 未自行指定名称的新终端自动命名：基础名为“终端”，后续为“终端1”“终端2”等，按用户最新“复用空号，下次叫终端1”的示例使用无括号名称；不批量改写已有显示名。
- 每个项目独立分配编号，上下区域共用，服务端统一分配而非浏览器计数。使用当前最小可用名称；终端成功终止或改名释放旧名称后可以复用。例如“终端”“终端1”“终端2”中关闭“终端1”，下次仍叫“终端1”；倒计时尚未结束或取消时不释放占用。
- 同项目其他存续终端（包括自定义名称）完全同名时跳过该候选；仅隐藏/上下移动不释放名字，状态未知不冒称已结束。保留既有自定义显示名可重复的兼容性，不把显示名当唯一资源身份；已结束历史记录不阻止空号复用。
- 双击标签可重命名该终端；右键菜单也提供“重命名”。用户名称是显示元数据，不改变稳定 terminal ID、tmux 进程身份、cwd 或控制权。
- 新增元数据更新须保持跨端与重启一致性，不将仅本端临时标签文字称为已持久化重命名。名称校验沿用现有 display_name 的合法性约束；自动编号复用不复用旧 terminal ID 或真实进程身份。
- 现有创建固定默认“终端”，没有编号分配和修改接口：`internal/terminal/service.go:39`、`internal/httpapi/router.go:139`、`internal/storage/terminals.go:32`。实现所需后端补充属于已请求能力的支持范围，协议签名待 design 审查，不冒称现有 API。

### UI08 右键菜单与批量倒计时

- 终端标签右键菜单包含：接管、刷新终端、重命名、关闭当前、关闭其他、全部关闭。
- “刷新终端”只重新读取终端列表和真实运行状态，保持既有刷新语义；不刷新/清空实时画面，不重建 xterm/WS、不主动重连、不接管、不重启 shell 或重跑命令。断线手动重试是独立操作，入口见 UI10。
- “关闭当前”作用于右键目标终端；“关闭其他/全部关闭”仅作用于当前标签所在区域：下方只影响下方，上方只影响上方，上下互不影响，不跨其他项目/浏览器布局。“关闭其他”保留右键目标终端。此处是终端右键菜单，文件标签不属于终端批量终止对象。
- 单个/批量关闭均进入倒计时。批量对话框展示将关闭的终端名称列表，开始倒计时后仍可取消；保留既有全端通知、可配置时长和鉴权规则。
- 2026-09-30 用户选择 Q04 方案1：批量关闭先列明目标和未接管项，由用户明确确认“接管并关闭”；成功取得全部目标控制权后才统一开始倒计时。有一项无法接管，不启动这批倒计时，列明失败对象，不静默跳过并部分关闭。仅接管成功的终端具备终止资格，不能通过直接 kill-session 或删除元数据绕过权限/倒计时。
- 接管成功以服务器返回的角色/generation 为准，不将请求已发送视为接管成功。接管确认前取消零接管/终止；接管失败后如部分对象已转移控制权，应如实显示已接管与失败状态，不宣称控制权变更可无副作用回滚。
- 批量倒计时作为一个统一批次：截止前任一有效查看端取消，或批次成员的控制权失效时，取消该批次全部目标，不让其余成员继续关闭。其他独立批次不受影响。用户已用 A/B/C 与独立 D/E 的例子确认该规则。
- 保留既有发起者认证失效/连接断开、控制转移、Web 重启取消 pending 的保守行为；批量倒计时截止前这些撤销规则对应受影响的整个批次，不取消无关批次。截止后的实际进程终止不可回滚，逐目标展示真实结果。
- 当前后端为每个 hub 独立计时/取消，没有批量请求及统一取消契约：`internal/terminal/termination.go:8`、`:37`、`:62`。统一截止和撤销协调由 design 锁定，不能只拼前端逐个请求后宣称统一批量安全。

### UI09 手机同步精简

- 2026-09-30 用户确认“同步精简”：手机项目工作台同步合并顶部栏、精简终端头部，不保留旧的多条常驻工具栏。
- 保留手机单内容视图，不增加并排拆分；保留 Ctrl/Alt/方向键及其他已批准的终端快捷操作栏。
- 手机通过可点击的“更多”菜单承接桌面的右键、悬停关闭和双击重命名操作，不依赖鼠标悬停或双击才能完成操作。接管图标及标签末尾 + 仍可直接触控。
- 终止权限、批次范围、名称列表、服务器倒计时与取消规则不因手机界面简化而改变。
- 窄屏顶部与标签栏须收纳长名称和操作项，保留中文提示与可访问名称，不通过横向撑大整页或遮挡终端输入解决空间不足。

### UI10 剩余入口与状态收纳

- 用户确认：历史、移到上方/移回下方、断线时的重试连接放进标签右键菜单，手机用“更多”；手机不提供上下移动。
- 历史视图继续支持返回实时画面和独立刷新历史快照，不把“刷新终端列表/状态”混作历史刷新。
- 终端面板标签行最右侧 X 仅收起面板，提示“收起终端面板”；标签末尾 X 则终止对应会话并进入倒计时，二者不混用。
- 初始工作目录放在标签提示中，不冒称 shell 实际 cwd；手机可从“更多”菜单的会话信息查看该目录。连接/运行状态使用有说明的小图标，断线及操作错误仍明确显示，不新增常驻状态工具栏。
- 顶栏窄屏收纳主题/退出等次要操作，但项目名称和必要导航保持可达。登录、项目列表不作外观重设计；统一终端页保持原有查看/创建边界，共享组件和协议更新不得退化其既有能力，也不新增跨全部项目的批量终止入口。

- AC13 / UI08：右键刷新仅触发列表/状态读取，原 xterm/DOM/WS 与实时画面保留，零额外连接、接管、输入或终止请求；读取失败准确展示，不用失败结果将仍在运行的终端判为已结束。
- AC14 / UI09：手机单内容视图及终端快捷键栏保留，通过“更多”菜单完成重命名/关闭等操作；单目录与多目录新建、接管及单个/批量取消流程均可触控，长标签不撑大 document；软键盘展开时不遮挡当前输入及必要操作。
- AC15 / UI10：菜单历史/返回实时、独立刷新历史、上下移动和断线重试均保留，手机不显示移动项；面板 X 零终止，标签 X 倒计时终止；目录描述准确、状态不是只用颜色表达；登录/项目列表/统一终端页回归测试通过，未新增跨项目批量终止入口。
