# 工作区索引

> 所有开发者的 AI 代理工作记录

---

## 概览

本目录汇总项目内各开发者与 AI 代理协作的记录。

### 文件结构

```
workspace/
|-- index.md              # 本文件：总索引
+-- {developer}/          # 每位开发者的目录
    |-- index.md          # 个人索引与会话历史
    |-- tasks/         # 任务文件（旧模板结构，见下方说明）
    |   |-- *.json        # 活动任务
    |   +-- archive/      # 按月归档的任务
    +-- journal-N.md     # 日志文件（顺序编号：1、2、3……）
```

---

任务的权威位置是 `.trellis/tasks/`；上方开发者目录内 `tasks/` 是旧模板示意，本项目不使用该结构，也不建立第二套任务系统。

## 开始使用

### 新开发者

运行身份初始化脚本：

```bash
python3 ./.trellis/scripts/init_developer.py <your-name>
```

此命令会：
1. 创建身份文件（不纳入 Git）
2. 创建工作记录目录
3. 创建个人索引
4. 创建初始日志文件

### 继续已有工作

1. 获取开发者名称：
   ```bash
   python3 ./.trellis/scripts/get_developer.py
   ```

2. 阅读个人索引：
   ```bash
   cat .trellis/workspace/$(python3 ./.trellis/scripts/get_developer.py)/index.md
   ```

## 维护规则

### 日志文件规则

- 每个日志文件**最多 2000 行**
- 达到上限时创建 `journal-{N+1}.md`
- 创建新文件时更新个人 `index.md`

### 会话记录格式

每次会话应包含：
- 摘要：一句话说明
- 分支：工作所用分支
- 主要修改：具体变更内容
- Git 提交：提交哈希与消息
- 后续步骤：下一步工作

---

## 会话模板

记录时使用以下模板。`## Session N:` 与 `**Date**:` 为脚本精确识别的格式，保留英文；会话标题和正文使用中文。

```markdown
## Session {N}: {会话标题}

**Date**: YYYY-MM-DD
**任务**：{task-name}
**分支**：`{branch-name}`

### 摘要

{一句话摘要}

### 主要修改

- {修改 1}
- {修改 2}

### Git 提交

| 哈希 | 消息 |
|------|---------|
| `abc1234` | {提交消息} |

### 验证

- [OK] {检查结果}

### 状态

[OK] **已完成** / # **进行中** / [P] **受阻**

### 后续步骤

- {后续步骤 1}
- {后续步骤 2}
```

---

**语言**：文档和会话正文使用**简体中文**；命令、代码标识符及机器定位标记保留原样。
